HTML / CSS 기능 실습 웹사이트

웹프로그래밍 수업에서 배운 list, form, media 기능을 각각의 페이지로 구현하고, 하나의 웹사이트처럼 연결하여 정리한 실습형 프로젝트입니다.

HTML CSS JavaScript
배포사이트 보기 목록으로

프로젝트 개요

HTML과 CSS의 다양한 기능을 직접 구현해보기 위해 제작한 실습형 웹사이트입니다. list, form, table, media 기능을 각각 페이지로 구성하고, 메뉴를 통해 하나의 사이트처럼 연결하였습니다.

제작 목적

수업에서 배운 HTML 태그와 CSS 스타일링을 실제 화면으로 구현하면서 기능의 활용 방법을 이해하고, 여러 페이지로 구성된 웹사이트 구조를 익히는 것을 목표로 하였습니다.

페이지 구성

  • Main : 사이트 소개 및 이동 기능
  • Table : 시간표 구성 페이지
  • List : 메뉴판 형태 목록 페이지
  • Form : 입력 양식 페이지
  • Media : 이미지, 오디오, 영상 페이지

주요 기능

  • 메뉴바를 통한 페이지 이동
  • list 태그 활용
  • form 입력 UI 구성
  • media 요소 삽입
  • table을 활용한 시간표 제작
  • CSS를 통한 레이아웃 및 디자인 구성

화면 미리보기

Table 페이지

저의 실제 대학교 시간표를 구현한 페이지입니다.

List 페이지

실제 학교 카페의 메뉴판을 구현한 페이지입니다.

Form 페이지

실제 문의하는 페이지의 이미지를 구현한 페이지입니다.

실제로 기능이 구현되지는 않습니다.

Media 페이지

영상과 음악을 들을수 있도록 구현한 페이지입니다.

내가 맡은 역할

전체 기획부터 HTML 구조 작성, CSS 스타일 적용까지 모든 과정을 직접 수행하였습니다.

배운 점

HTML과 CSS를 실제로 활용하여 웹사이트를 구성하면서 레이아웃 설계와 UI 구성의 중요성을 이해할 수 있었습니다.
