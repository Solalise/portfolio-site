HTML / CSS 기능 실습 웹사이트

웹프로그래밍 수업에서 배운 list, form, media 기능을 각각의 페이지로 구현하고, 하나의 웹사이트처럼 연결하여 정리한 실습형 프로젝트입니다. 각 페이지는 상단 메뉴를 통해 이동할 수 있으며, 배운 내용을 실제 화면으로 구현해 보는 데 중점을 두었습니다.

HTML CSS JavaScript

프로젝트 개요

이 프로젝트는 웹프로그래밍 수업에서 배운 다양한 HTML 태그와 CSS 스타일링을 직접 적용하여 제작한 실습형 웹사이트입니다. list, form, media, table등의 기능으로 각각 별도의 페이지를 구성하고, 메뉴를 통해 서로 연결하여 하나의 사이트처럼 보이도록 제작하였습니다. 단순히 기능을 따로 연습하는 것이 아니라, 실제 웹사이트 구조 안에서 정리해 보며 각 요소의 활용 방식을 익히는 데 목적을 두었습니다.

제작 목적

수업에서 배운 HTML과 CSS 내용을 직접 화면으로 구현하면서 각 태그와 속성의 역할을 더 정확히 이해하고자 하였습니다. 또한 여러 기능을 각각의 페이지로 구성한 뒤 메뉴바를 통해 연결해 보면서, 단일 페이지가 아닌 여러 페이지로 이루어진 웹사이트의 기본 구조를 직접 연습해 보는 것을 목표로 하였습니다.

페이지 구성

  • Main : 배경색을 바꾸거나, 다른 사이트와 연결하는 등의 여러 기능이 탑재된 페이지
  • Table : 표 형식으로 시간표를 만든 페이지
  • List : 메뉴판 형식으로 목록을 정리한 페이지
  • Form : 입력 양식과 버튼을 배치한 페이지
  • Media : 이미지, 오디오, 비디오를 삽입한 페이지

주요 기능

  • 상단 메뉴바를 통한 페이지 이동
  • list 태그를 활용한 메뉴판 형태의 목록 구성
  • form 태그를 활용한 입력 화면 구성
  • media 태그를 활용한 이미지, 오디오, 비디오 삽입
  • table 태그를 활용한 시간표 생성
  • CSS를 활용한 배경색, 박스, 여백, 정렬 스타일 적용
  • 전체 페이지를 통일된 디자인으로 연결한 웹사이트 형태 구현

화면 미리보기

Table 페이지

table 태그를 활용하여 학교 시간표를 구성해보았고, 에브리타임 시간표와 최대한 비슷하도록 색상과 크기를 조절하며 표현하였습니다.

List 페이지

list 태그를 활용하여 카페 메뉴판 형식으로 구성하였고, 제목과 가격 배치를 통해 실제 메뉴판처럼 보이도록 표현하였습니다.

Form 페이지

입력창, 선택 항목, 버튼 등을 활용해 정보를 입력할 수 있는 양식 형태의 화면을 제작하였습니다.

Media 페이지

이미지, 오디오, 비디오를 삽입하고 박스 형태로 정리하여 각 미디어 요소가 구분되어 보이도록 구성하였습니다.
